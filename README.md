# skills-repo — скиллы для Claude Code

Скиллы ставятся через [skills CLI](https://skills.sh):

```bash
npx skills add Vitvit2025/skills-repo@graphiti-memory -g -y     # → ~/.agents/skills/graphiti-memory (+ симлинк в ~/.claude/skills)
npx skills update                                            # обновить все
```

Перед установкой любого стороннего скилла читай его SKILL.md и скрипты целиком — он работает с полными правами агента.

## graphiti-memory — графовая долговременная память для Claude Code

**Что делает.** Память ассистента в виде графа знаний на вашем сервере: из заметок и рабочих сессий строятся
карточки (серверы, сервисы, боты, люди, проекты, книги) и датированные факты между ними — с историей, что было верно
раньше и когда перестало. Ассистент ищет по смыслу («что мы решали про X», «что зависит от Y», «сводка темы») и
дописывает выводы сессий. Полный цикл: развернуть → загрузить корпус → ночная докачка → контроль качества и секретов → ремонт.

**На какой базе.** [Graphiti](https://github.com/getzep/graphiti) (темпоральный граф знаний, Apache-2.0) +
[FalkorDB](https://falkordb.com) (графовая база на Redis) в одном контейнере `zepai/knowledge-graph-mcp` с MCP-сервером;
модели через OpenRouter (дешёвая на извлечение, сильная на дедуп/противоречия, эмбеддер bge-m3). Патчи поверх
graphiti-core без правки библиотеки: векторный индекс, быстрый полнотекст, свои промпты дедупа, поиск по сообществам.

**Из каких данных.** Файловая память Claude Code (`memory/*.md`, источник истины), дайджесты транскриптов сессий
(решения / тупики с причиной / открытые вопросы / правила владельца), Telegram-инбокс владельца, архивы с прежних
серверов. Всё — через фильтр секретов (словарь реальных значений с сервера + регулярки + энтропия) и контрольный прогон по графу.

**Что внутри.** [`SKILL.md`](skills/graphiti-memory/SKILL.md) — режимы «развернуть» и «работать»;
[`reference/memory-guide.md`](skills/graphiti-memory/reference/memory-guide.md) — подробная инструкция с граблями
(3 редакции, 15–16.09.2026); [`reference/runbook.md`](skills/graphiti-memory/reference/runbook.md) — команды;
[`scripts/`](skills/graphiti-memory/scripts/) — загрузчики, патчи, фильтр секретов, дайджесты, метрики, ремонт;
[`examples/`](skills/graphiti-memory/examples/) — пример боевого конфига (без секретов).

Цифры с живого сервера: 8 тыс. карточек / 36 тыс. фактов, сборка корпуса ≈ $25 и 9 ч фоном, докачка ≈ $0.3–0.8/ночь,
поиск 0.2–1.3 с.
